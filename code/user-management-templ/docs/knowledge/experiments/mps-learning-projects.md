~15 projects in MPSProjects/ and 2 in DLS/toys/ were purely for learning JetBrains MPS.

## The Very Beginning: DLS/toys/ (Feb 4-6, 2025)
The first MPS workspace, before MPSProjects/ existed:
- **math** (AlgebraLang) — first algebra DSL attempt
- **noname** — unnamed first experiment
These are the earliest MPS experiments. After this, work moved to `MPSProjects/`.

## Go Syntax Recreation (Learning Language Design)
Multiple attempts to recreate Go-like syntax in MPS to learn:
- **gtog** — Go-to-Go, most complete (has README), learned syntax checks, refs, scoping
- **golangTgolang**, **gfunc**, **gg**, **gltogl** — clean-slate restarts of the same idea
- Purpose: learn MPS language design aspects — not to produce a useful tool

## Tutorial-Based Projects
- **AlgebraL2** — Algebra/math DSL (from MPS tutorials)
- **claculator** — Calculator DSL (tutorial, note the typo)
- **shape** / **newShape** — Shape DSLs (tutorial exercises)

## Quick Experiments
- **config** / **congifLang** — Configuration language attempts (typo in name = fast iteration)
- **DEC**, **TaskMaster** — Small experiments
- **throwed** — possibly "thrown away"
- **t**, **test**, **testtttt** — test projects (increasing desperation in naming)

## Pattern: Typos = Speed
Multiple projects have typos in names (`claculator`, `congifLang`, `testtttt`). This indicates rapid creation — moving fast, not polishing. The learning was in building, not naming.
