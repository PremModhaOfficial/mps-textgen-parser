# DSL Development Learnings — Knowledge Graph

Obsidian-style linked markdown capturing all learnings from building the MPS DSL across multiple projects.

## Purpose
This graph is a **reusable AI context layer**. Instead of `!ls` and `!tree` every time, AI reads `_index.json` + relevant nodes to compile targeted outputs:
- Meeting presentations
- Blog posts
- Internal documentation
- Onboarding material

## Structure
- Each `.md` file is a **knowledge node** with YAML frontmatter
- `[[wiki-links]]` create connections between nodes
- `_index.json` is auto-generated by `build_index.py` — never edit it directly
- `images/` holds MPS editor screenshots

## Upstream/Downstream
- `docs/knowledge/` = **upstream** (raw capture, edited during interviews)
- `docs/sections/*.adoc` = **downstream** (polished Feynman docs compiled from this graph)
