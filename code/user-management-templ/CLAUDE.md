# MotaDSLUM — NATS User Management Microservice

## Project Layout
- `src/main.go` — NATS microservice entry point (DSL-generated, DO NOT hand-edit)
- `src/user.go` — User entity handler (DSL-generated)
- `src/roles.go` — Roles entity + RolesPermissions relation handler (DSL-generated)
- `src/permissions.go` — Permissions entity handler (DSL-generated)
- `src/userDefinedHooks.go` — Hook implementations (SAFE to edit, preserved across syncs)
- `src/sqlPrem_init_sql.sql` — Generated SQL schema
- `merge_hooks.py` — Extracts hook stubs from generated code, merges into userDefinedHooks.go
- `sync.sh` — Copies MPS output + SDK into project, runs merge_hooks.py, builds Docker
- `demo.sh` — Integration test (21 tests, connects to docker compose on port 4229)
- `motadata-go-sdk/` — Vendored SDK (synced from ~/projects/nextgen/gosdk/ by sync.sh)

## Critical: Code Generation Flow
```
MPS DSL (~/UserManagmentMps/) → TextGen → sync.sh → src/*.go (OVERWRITES)
```
Only `src/userDefinedHooks.go` survives sync. All other `src/*.go` are regenerated.
To make permanent changes: modify TextGen templates in MPS, not the generated Go files.

## Architecture
- NATS microservice using `nats.go/micro` + Motadata Go SDK
- Subject pattern: `motadata.{entity}.{operation}` → handler → `motadata.{entity}.db.{operation}` (DAL)
- OTEL tracing via SDK's otel/tracer package
- Hooks: pre/post on every CRUD op, 4 signatures (sync/async × pre/post)
- Docker Compose: NATS on port 4229 (external), app connects internally on 4222

## Key Tools
- `merge_hooks.py` — Keys by `*ReceiverType.funcName` to avoid collisions, detects signature changes
- `sync.sh` — Copies .go/.sql from MPS, runs merge, rsyncs + patches SDK module paths
- `demo.sh` — 21 e2e tests via `nats req` against docker compose app

## Terminology
- **Entity**: Domain object (User, Roles, Permissions) defined in MPS DSL
- **Relation**: M:N relationship (UserRoles, RolesPermissions) defined in MPS DSL
- **TextGen**: MPS code generation templates that produce .go files
- **Hook stub**: Empty pre/post function generated by TextGen, extracted into userDefinedHooks.go
- **DAL**: Data Access Layer (downstream NATS consumer, not in this repo)
